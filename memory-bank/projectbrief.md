# FitZone Gym - Project Brief

## Overview
FitZone Gym is a 6-page website for a gym located in Kadikoy, Istanbul. The design is energetic with dark backgrounds and orange accents.

## Tech Stack
- Next.js 15 (App Router, TypeScript)
- Tailwind CSS v4
- Framer Motion (animations)
- GSAP + @gsap/react (available for advanced animations)
- Lenis (smooth scrolling - available)
- clsx (conditional classes)

## Design System
- **Colors:** #0D0D0D (black bg), #FF6B00 (orange accent), #141414 (card bg), #888 (muted text), #FFF (white)
- **Fonts:** Oswald (headings, condensed, uppercase, bold) + Inter (body text)
- **Style:** Dark, aggressive, energetic. All headings UPPERCASE. Orange top borders on cards.

## Pages
1. **Home (/)** - Hero, Services, Stats, Trainers preview, CTA, Transformations
2. **Membership (/uyelik)** - 3 pricing cards + comparison table
3. **Trainers (/antrenorler)** - 10 trainers in 3-column grid
4. **Schedule (/program)** - Weekly calendar, color-coded classes
5. **Gallery (/galeri)** - Masonry grid + filters + lightbox
6. **Contact (/iletisim)** - Form + info + map placeholder
